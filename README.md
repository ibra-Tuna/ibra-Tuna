### Open source

**[Godot-Rain-System](https://github.com/ibra-Tuna/Godot-Rain-System)** —
drag-and-drop 2D rain for Godot 4. One node, everything generated at runtime:
auto-detects your TileMaps and StaticBodies, builds SDF colliders on the fly,
and spawns GPU sub-emitter splashes where the rain lands. Four presets from
Light Rain to Storm, plus `fade_in()` / `stop()` for weather changes. Requires
Godot 4.3+ on Forward+ or Mobile for real splashes.

**[godot-2d-character-controller](https://github.com/ibra-Tuna/godot-2d-character-controller)**
— a 2D character controller focused on game feel. Every movement value is an
`@export` variable, so acceleration, friction, and run-jumps are all tunable
from the Inspector. Archived, kept public for anyone learning.
